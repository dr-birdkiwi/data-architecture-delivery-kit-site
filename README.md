# Data Architecture Delivery website

Public services website for expert-led data architecture, optional implementation, modernization, and continuous data assurance. The internal delivery kit is not exposed by the website.

## Live site

[https://dr-birdkiwi.github.io/data-architecture-delivery-kit-site/](https://dr-birdkiwi.github.io/data-architecture-delivery-kit-site/)

## Local build

```bash
npm ci
npm run build
```

The site is statically exported by Next.js and deployed through GitHub Actions.
